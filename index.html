    →Pack size calculator

    Monocarton L, B & H fill in automatically once the artwork is uploaded as a PDF: it measures the printed die-line/crease grid pixel-for-pixel (Front/Back panel width = Length, Side panel width = Breadth, main-row height = Height), falling back to the artwork's own blue measurement lines if no die-line grid is found, then to the full design size for L & B only — adjust any value if needed. Only PDFs carry real physical scale; a plain image can't auto-measure. The expected Inner size is calculated automatically and checked against the Inner artwork when you compare. Defaults below are set for a standard pack of 12.
